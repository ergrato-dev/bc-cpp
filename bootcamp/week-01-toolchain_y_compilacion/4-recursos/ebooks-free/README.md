# 📚 Ebooks Gratuitos — Semana 01: Toolchain y compilación

Todo lo de esta lista es gratuito y legal. Cada entrada dice por qué vale la pena esta
semana, no solo qué es.

---

### C++ Core Guidelines

- **Autores**: Bjarne Stroustrup, Herb Sutter y la comunidad (ISO C++)
- **Formato**: web, un solo documento largo, actualizado continuamente
- **Enlace**: https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines
- **Por qué leerlo**: es la lista de reglas de C++ moderno escrita por quienes diseñan el
  lenguaje, con el porqué de cada una. Este bootcamp sigue estas reglas; cuando una
  teoría diga "no hagas X", casi siempre hay una regla aquí que lo explica mejor.
- **Secciones para esta semana**: `ES.20` (inicializa siempre), `ES.23` (prefiere `{}`),
  `ES.45` (evita constantes mágicas), `ES.48` (evita casts), `Enum.3` (`enum class`),
  `SL.io.50` (evita `endl`).

---

### Modern C++ Tutorial: C++11/14/17/20 On the Fly

- **Autor**: Changkun Ou
- **Formato**: web y PDF, ~150 páginas, licencia CC BY-NC-ND
- **Enlace**: https://changkun.de/modern-cpp/
- **Por qué leerlo**: un recorrido compacto por lo que cambió desde C++11, con código.
  No es para principiantes absolutos (asume que sabes C++98), así que úsalo como mapa:
  cuando una teoría mencione "esto es de C++17", aquí ves el antes y el después.
- **Capítulos para esta semana**: 1 (Introduction) y 2.1-2.3 (constants, variables,
  `auto`). El resto llegará semana a semana.

---

### C++ Annotations

- **Autor**: Frank B. Brokken (Universidad de Groninga)
- **Formato**: web, PDF, ePub; muy extenso; se actualiza cada año
- **Enlace**: https://fbb-git.gitlab.io/cppannotations/
- **Por qué leerlo**: es un libro universitario completo y gratuito, pensado para quien
  viene de C. Denso, pero riguroso: cuando quieras el detalle de algo, suele estar.
- **Capítulos para esta semana**: 1 (Overview), 3.1-3.4 (tipos, `auto`, literales).

---

### Learn C++ (learncpp.com)

- **Autor**: Alex (mantenido por la comunidad)
- **Formato**: web, lecciones cortas numeradas
- **Enlace**: https://www.learncpp.com/
- **Por qué leerlo**: es el tutorial gratuito de C++ mejor mantenido para principiantes.
  Explica más despacio que este bootcamp y con más ejemplos. Si una teoría te va rápida,
  la lección equivalente de aquí te da la segunda pasada.
- **Capítulos para esta semana**: 0 (Introduction, incluido 0.5 sobre compiladores), 1
  (C++ Basics) y 4 (Fundamental Data Types).
