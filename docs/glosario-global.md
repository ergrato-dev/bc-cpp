# 📖 Glosario global

Índice A-Z de todos los términos definidos en los `5-glosario/README.md` de cada semana,
con el término inglés del estándar entre paréntesis y la semana en la que se define.

Formato de cada entrada:

```markdown
### término en español (english term)
Definición de una o dos líneas. → Semana NN
```

Se construye al publicar cada semana. Cuando dos semanas definan el mismo término, gana
la primera y la segunda enlaza.
