# 🤝 Código de Conducta

## Nuestro compromiso

Este bootcamp existe para enseñar C++ moderno de forma rigurosa y accesible, empezando
desde cero absoluto. Esperamos de cualquier persona que participe (estudiantes,
instructores, colaboradores externos) un trato respetuoso, sin importar nivel de
experiencia, origen, género, orientación, discapacidad o cualquier otra característica
personal.

## Se espera

- Dar y recibir revisión de código de forma constructiva. La crítica va al código, al
  diseño o a la medición; nunca a la persona que los hizo.
- Respetar el ritmo de aprendizaje de otros. Aquí se asume explícitamente que hay gente
  que nunca ha programado, y esa es la audiencia principal. "Esto es básico" no es un
  comentario útil.
- Reportar código que no compila, ejemplos con comportamiento indefinido o contenido
  desactualizado de forma concreta y verificable (semana, archivo, compilador y versión
  donde lo comprobaste).
- Reconocer que el contenido de este repositorio está generado con asistencia de IA y
  revisado por el autor. El estándar de calidad es el mismo independientemente de la
  herramienta usada para producirlo: todo compila, todo tiene test.

## No se tolera

- Acoso, insultos o comentarios despectivos hacia cualquier persona.
- Menospreciar a alguien por su equipo, su sistema operativo o su editor. Un portátil
  con WSL2 y `g++` es todo lo que este bootcamp necesita.
- Compartir públicamente datos personales de otros (*doxxing*) sin consentimiento.
- **Copiar el proyecto de otro estudiante**, aunque sea de otro dominio y renombrando.
  La política de dominios únicos existe para que eso no compense; hacerlo es 0 en
  Producto esa semana y, si se repite, salida del programa. Ver
  [`docs/dominios.md`](docs/dominios.md).
- Publicar en los starters código con comportamiento indefinido "que funciona" sin
  marcarlo. Enseñar con un ejemplo roto hace daño a quien lo copia.
- Spam o autopromoción no solicitada en issues y pull requests de este repositorio.

## Aplicación

Los incidentes se reportan a **elparcheti@gmail.com**. Todo reporte se revisa caso por
caso; las respuestas van desde una advertencia privada hasta la remoción de acceso al
repositorio o al programa, según la gravedad.

## Alcance

Aplica a cualquier espacio asociado al bootcamp: este repositorio (issues, pull
requests, discussions, commits) y cualquier canal de comunicación oficial del programa
donde se discuta su contenido.
